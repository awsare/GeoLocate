Pipeline

Reproduction follows the same training/evaluation pipeline documented in the repository.

download_dataset.py -> prepare_dataset.py -> train.py -> evaluate.py -> evaluate_distance.py

Core Commands

pip install -r requirements.txt
python download_dataset.py
python prepare_dataset.py
python train.py
python evaluate.py
python evaluate_distance.py

Website Update Workflow

  1. Update metrics in website/assets/results.json.
  2. Run a local preview from the website folder.
  3. Commit and push to trigger GitHub Pages deployment.
cd website
python -m http.server 8000
This website is static by design and does not perform live model inference.
